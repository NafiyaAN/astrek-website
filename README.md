# Elevate Suite

A premium, animated marketing site for Astrek Innovations — built with TanStack Start, React, and Vite.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Build

```sh
npm run build
```
